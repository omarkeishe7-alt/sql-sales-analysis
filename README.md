# SQL Sales Analysis

## Project Overview
This project focuses on analyzing sales data using SQL to explore sales performance, identify patterns, and generate meaningful business insights.

## SQL Skills Used
- Common Table Expressions (CTEs)
- Joins
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- Window Functions
- CASE WHEN

## Analysis Objectives
- Analyze sales performance across different years.
- Compare product sales.
- Calculate averages and identify sales trends.
- Use SQL to extract meaningful insights from raw data.

## Tools
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Project Goal
To develop practical SQL skills and demonstrate how data analysis can support better business decisions.
